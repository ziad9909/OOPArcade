Detailed Description

Main entry point for OOP Game Arcade application.

Author
CS213 Assignment 3 Team
Date
December 2025

This file contains the main menu system that allows users to select and play different Tic-Tac-Toe game variants. It integrates all game implementations and provides a unified interface.

Available Games:

  1. Numerical Tic-Tac-Toe (Group Game 9)
  2. Classic X-O (Demo)
  3. Misère Tic-Tac-Toe
  4. SUS
  5. Word Tic-Tac-Toe
  6. 4x4 Moving Tic-Tac-Toe
  7. Obstacle Tic-Tac-Toe
  8. Infinity Tic-Tac-Toe
  9. Four-in-a-Row (Connect 4)
  10. Diamond Tic-Tac-Toe
  11. 5x5 Tic-Tac-Toe
