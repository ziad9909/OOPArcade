Detailed Description

Board class for 4x4 Moving Tic-Tac-Toe where players move existing tokens.

This board variant features a 4x4 grid where players start with 4 pre-placed tokens each. Instead of placing new tokens, players move their existing tokens one step horizontally or vertically. The objective is to align three tokens in a row.

  • O tokens at positions (0,0), (0,2), (3,1), (3,3)
