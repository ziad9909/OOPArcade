Detailed Description

Board class for Pyramid Tic-Tac-Toe with triangular structure (3 levels: 1+2+3 cells).

Implements a pyramid-shaped board with 3 levels:

  • Level 1 (top): 1 cell
  • Level 2 (middle): 2 cells
  • Level 3 (bottom): 3 cells

Players aim to get three of their symbols in a row following the unique geometric patterns of the pyramid structure.
