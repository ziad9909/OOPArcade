Detailed Description

Board class for Numerical Tic-Tac-Toe.

Implements Numerical Tic-Tac-Toe where players use numbers and win by getting three numbers in a line that sum to 15.

Numerical_TTT_Board::Numerical_TTT_Board ( )

Constructor for Numerical Tic-Tac-Toe board.

Initializes 3x3 board and number pools:

  • Player 1 gets odd numbers: 1, 3, 5, 7, 9
  • Player 2 gets even numbers: 2, 4, 6, 8
